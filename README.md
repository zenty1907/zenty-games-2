# Zenty Games 2 🎮

Ücretsiz, mobil uyumlu mini oyun portalı. Harici kütüphane veya kurulum gerektirmez.

## Oyunlar
- 🐍 Neon Yılan
- 🚀 Uzay Savunması
- 🧱 Blok Kırıcı
- 🧠 Hafıza Eşleştirme
- 🏃 Neon Koşucu
- ⚡ Refleks Testi

## GitHub Pages ile yayınlama
1. Repository → **Settings** → **Pages** bölümünü aç.
2. **Deploy from a branch** seç.
3. Branch olarak **main**, klasör olarak **/(root)** seç ve kaydet.
4. Yayınlama tamamlanınca siten GitHub Pages adresinde açılır.

Ana sayfa `index.html` dosyasıdır. Oyunlar doğrudan tarayıcıda çalışır.
